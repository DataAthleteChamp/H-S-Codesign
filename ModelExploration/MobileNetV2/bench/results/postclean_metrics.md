## Augmentation-robustness panel (n = 780, biased — informational only)

The pre-cleanup augmented panel (60 originals + 720 augmented = 780
rows) is preserved for reproducibility by
`python/bench/build_full_aug_test.py`, which reads the 60 originals
from `data/<class>/test/` and the 720 quarantined augmented variants
from `data/_quarantine/test_augmented/<class>/` (never repolluting the
test split). The script writes
`bench/results/jakubs_qat_full_aug_test.npz`, which is consumed by
`make stats` for the augmentation-robustness panel of
`bench/results/stats_summary.md`.

| Metric | Value |
|---|---:|
| n (rows) | 780 (60 originals + 720 quarantined augmented) |
| accuracy | 97.69 % (762 / 780) |
| macro-F1 | 0.9769 |
| Δacc vs originals-only | −0.64 pp |

This panel is *not* statistical evidence — its 780 rows derive from
the same 60 captures, so they are not independent. It is reported only
as an augmentation-robustness diagnostic (Kapoor & Narayanan 2023).
Headline statistical claims use only the n = 60 originals panel.

## Code changes that prevent recurrence

1. `python/augment.py` — explicit `TRAIN_ONLY = True` constant plus a
   post-run guard `_assert_test_split_clean(...)` that raises
   `SystemExit(2)` if any file under `data/<person>/test/` matches an
   augmentation suffix.
2. `python/preprocess.py` — `load_and_preprocess_split` now skips files
   whose stem ends with any `AUG_SUFFIXES` when `split == 'test'`, and
   `preprocess_all` raises if per-class test counts are not balanced.
3. Both modules import `AUG_SUFFIXES` from
   `python/utils/train_val_split.py`, so the definition of "augmented"
   has a single source of truth across the cleanup tool, the augment
   script, and the preprocessor.
